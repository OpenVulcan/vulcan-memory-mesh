# 检索报告复核与修正计划

## 任务目标

- 结合用户补充的技术方向，重新评估当前检索与记忆升级报告中的判断。
- 修正原报告中需要收紧、放宽或补充的结论。
- 输出一份更新后的分析文档，覆盖：
  - 混合检索
  - 交叉编码器重排序
  - MMR 多样性控制
  - Weibull 衰减与三层晋升
  - 情境化记忆
  - 支持/反驳统计
  - 多 rerank provider
  - 语义去重
  - 自适应检索

## 执行步骤

1. 复查当前报告的结论与建议边界。
2. 对照现有代码结构，逐项评估新增技术点的真实可行性与改造成本。
3. 明确哪些内容应升级为“推荐方案”，哪些应下调为“中长期方向”。
4. 修正并补充文档，细化到表结构、接口与流程建议。
5. 完成自检并按计划要求重命名计划文件。

## 分析原则

- 以当前仓库真实实现为准，不把理想架构直接当成既有条件。
- 优先给出工程上可落地、可回滚、可分阶段实施的建议。
- 对新增能力按“短期可落地 / 中期可演进 / 长期方向”分层。

## 验收标准

- 明确指出原报告哪些判断需要修正。
- 给出修正后的推荐优先级。
- 给出补充后的表结构、接口与配置建议。
- 形成一份新的完整分析文档，可直接替换原报告使用。
